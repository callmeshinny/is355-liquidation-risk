# Liquidation risk project

This project develops a liquidation-risk model and a test plan for a tiered lending protocol.

Set up the environment with `bash tools/setup_env.sh`. If the FinSurvival data is absent, run `bash tools/get_data.sh`.

Run the report checks with `.venv/bin/python tools/check_report.py` and build the report with `bash tools/build_docx.sh`. Phase-specific commands are listed in `docs/CHECKLIST.md`.
